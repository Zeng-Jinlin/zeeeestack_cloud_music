# 前端UI重写计划

## 项目概述
重写zeeeestack云音乐的前端UI设计，打造一个活泼开放、充满年轻个性的个人音乐平台。以logo中的淡粉色为主色调，搭配中性白黑，保持视觉舒适不刺眼。

## 配色方案设计

### 核心配色理念
- **主色调**: 淡粉色系 - 温柔、活泼、年轻
- **辅助色**: 中性白黑 - 保持专业、舒适
- **强调色**: 少量点缀 - 画龙点睛，不滥用

### 详细配色
```
// 主色调 - 淡粉色系
$primary-1: #FFB6C1;    // 淡粉色 (主)
$primary-2: #FFC0CB;    // 浅粉色
$primary-3: #FFD1DC;    // 极浅粉色
$primary-4: #FFE4E9;    // 超浅粉色

// 中性色 - 白黑
$white: #FFFFFF;
$gray-50: #FAFAFA;
$gray-100: #F5F5F5;
$gray-200: #EEEEEE;
$gray-300: #E0E0E0;
$gray-400: #BDBDBD;
$gray-500: #9E9E9E;
$gray-600: #757575;
$gray-700: #616161;
$gray-800: #424242;
$gray-900: #212121;
$black: #000000;

// 点缀色 (少量使用)
$accent-pink: #FF69B4;    // 热粉色 (仅用于强调)
$accent-coral: #FF6B6B;    // 珊瑚红 (仅用于强调)
```

## UI设计原则

1. **温柔活泼** - 淡粉色营造年轻感，但不过度使用
2. **视觉舒适** - 文字使用黑白灰，避免刺眼
3. **简约现代** - 留白充足，布局清晰
4. **年轻个性** - 通过动效和细节体现活力
5. **配色克制** - 淡粉色作为点缀，不喧宾夺主

## 重写内容

### 1. App.vue - 主应用布局
- **背景**: 纯净白色或极浅粉色渐变背景
- **顶部导航栏**: 白色背景 + 淡粉色细边/图标点缀
- **Logo**: 突出显示，保持品牌感
- **整体风格**: 干净、明亮、温馨

### 2. MusicList.vue - 音乐列表页面
- **卡片设计**: 白色卡片 + 淡粉色悬停效果
- **列表项**: 简洁布局，淡粉色播放按钮
- **封面展示**: 圆角设计，白色边框
- **空状态**: 温馨的空状态提示
- **加载状态**: 柔和的加载动画

### 3. MusicPlayer.vue - 音乐播放器
- **播放器样式**: 白色浮动播放器 + 淡粉色进度条
- **控制按钮**: 淡粉色播放/暂停按钮
- **进度条**: 淡粉色渐变进度条
- **整体风格**: 精致、温馨、现代

### 4. SongDetail.vue - 歌曲详情组件
- **封面展示**: 白色圆角卡片
- **信息展示**: 黑色标题 + 灰色副标题
- **动画效果**: 播放时淡粉色光晕效果

## 实施步骤

1. 更新 `quasar-variables.sass` - 定义新的配色方案
2. 更新 `main.js` - 配置Quasar主题
3. 重写 `App.vue` - 主布局
4. 重写 `MusicList.vue` - 音乐列表
5. 重写 `MusicPlayer.vue` - 播放器
6. 重写 `SongDetail.vue` - 歌曲详情
7. 测试和优化

## 设计细节规范

### 文字颜色使用规范
- **主要文字**: `$gray-900` (深灰接近黑)
- **次要文字**: `$gray-600` (中灰)
- **辅助文字**: `$gray-500` (浅灰)
- **强调文字**: `$primary-1` (淡粉色，仅用于重要强调)

### 粉色使用规范
- ✅ 按钮图标
- ✅ 进度条
- ✅ 悬停效果
- ✅ 小面积装饰
- ❌ 大面积背景
- ❌ 文字主体
- ❌ 过度使用

### 圆角规范
- 小元素: 8px
- 中等元素: 12px
- 大元素/卡片: 16px

### 阴影规范
- 轻微阴影: `0 2px 8px rgba(255, 182, 193, 0.15)`
- 中等阴影: `0 4px 16px rgba(255, 182, 193, 0.2)`

- 温馨活泼的年轻感
- 视觉舒适不刺眼
- 淡粉色恰到好处的点缀
- 简约现代的设计风格
- 优秀的用户体验
